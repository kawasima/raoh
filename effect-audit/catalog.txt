# The effect of each external member Raoh's bytecode uses (#151).
#
# raoh-effect-audit-maven-plugin fails the build when raoh, raoh-json or raoh-jooq uses a member
# this file does not list. A member is written as the class file refers to it, return type
# included: java.util.List#get(int):java.lang.Object, java.util.Locale#ROOT:java.util.Locale.
#
# Each member is filed under the effect its API contract gives it, not under what its current
# implementation happens to do. Map and Set iteration order is not part of any contract Raoh
# relies on, so Map.of's per-JVM iteration order is not an effect.
#
# CLOSED     Runs no code a caller of Raoh can supply and acquires nothing outside its receiver
#            and arguments. A member no subclass can override may still delegate: a final method
#            that calls an overridable one on its receiver, or a method that calls methods of an
#            argument whose type a caller can implement (a CharSequence, a Collection, an
#            Object's hashCode). Those are DELEGATED.
# EXPLICIT   Like CLOSED, except that the ambient value it depends on is an argument:
#            String#toLowerCase(Locale).
# DELEGATED  May run code chosen by its receiver, an argument, or a class it initializes. Each
#            use needs an approval in effect-audit/<module>.txt, whose reason says whether the
#            use only observes what Raoh accepted (allowed) or adopts a caller's behaviour as the
#            meaning of a conversion (not allowed; fix the code as #152 did).
# AMBIENT    Acquires ambient state itself: default locale, time zone, clock, randomness, class
#            path, filesystem, network. Each use needs an approval, and decoder code must not
#            reach one, directly or through Raoh's own methods.
#
# The audit rejects CLOSED and EXPLICIT for a method a subclass can override that is called
# virtually. A note after "  -- " is for the reader.
