# The effect of each external member Raoh's bytecode uses (#151).
#
# The raoh-effect-audit-maven-plugin fails the build when raoh, raoh-json or raoh-jooq uses a
# member this file does not list. Each member is filed under the effect its API contract gives
# it, not under what its current implementation happens to do: Map.of randomizes iteration
# order per JVM, but iteration order is not part of a Map's contract, so Map.of is CLOSED.
#
# CLOSED     Acquires nothing outside its receiver, its arguments and what they explicitly
#            reach. Observing an argument through its interface (the chars of a CharSequence,
#            the elements of a Collection, a key's equals/hashCode) stays CLOSED.
# EXPLICIT   The ambient value it depends on is an argument: String#toLowerCase(Locale).
# DELEGATED  Runs code the receiver or an argument chooses: any overridable method called
#            virtually, and a method that converts an argument into another value through the
#            argument's own methods (String.valueOf(Object) through toString()). Each use needs
#            an approval in effect-audit/<module>.txt.
# AMBIENT    Acquires ambient state itself: default locale, time zone, clock, randomness,
#            class path, filesystem, network. Each use needs an approval, and none is allowed
#            in a decoder package.
#
# CLOSED and EXPLICIT are only for members no subclass can override; the audit checks this.
# A note after "  -- " is for the reader.
